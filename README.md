# Fasti

> **一本带时间维度的个人事实台账** —— 把"关于我是谁"的记录，变成任何 AI Agent 都能直接读懂的上下文。

Fasti 是一个**本地优先的个人画像工具**。你录入关于自己的事实（技术栈、当前项目、偏好、目标……），它维护这些事实随时间的变化，并渲染成 `AGENTS.md` / `CLAUDE.md` / `.cursor/rules` 等文件，让 AI Agent 在会话开始时就知道你是谁。

---

## 它解决什么问题

每开一个新会话，你都要重新介绍自己：我是做什么的、用什么语言、当前在什么项目、喜欢什么样的回答。

Fasti 把这些信息收拢成一份**可维护、可追溯、可迁移**的画像，放在 Agent 会读取的位置。

**它的核心不是"记住更多事实"，而是"表达变化"。**

| 场景 | Fasti 的处理 |
|---|---|
| 你从 Python 转到了 C++ | 记为**演进**：当前是 C++，历史保留"2025-01 至 2026-10 是 Python" |
| 你之前把主力语言写错了 | 记为**纠正**：区间不变，只改内容，原值保留在修订历史里 |
| 你换了一个 Agent | 同一份画像渲染成该宿主认识的格式 |

## 快速开始

**要求**：Python 3.9+，**零第三方依赖**（仅标准库）。

```bash
cd workspace

# 1. 初始化数据目录（默认 ~/.fasti）
python3 run.py init

# 2. 录一条事实
python3 run.py fact add --category tech --content "主力语言：Python" --valid-from 2025-01

# 3. 生成画像并渲染到宿主文件
python3 run.py render

# 4. 查看当前画像
python3 run.py profile show

# 5. 打开图形界面（推荐）
python3 run.py web
```

`web` 会在本机回环地址启动单页表单并自动打开浏览器，所有录入/修改/渲染都能在界面上完成。

### 接入 AI Agent

```bash
python3 run.py install-host
```

会把渲染产物放到宿主的**用户级全局位置**，一次放置、所有项目生效：

| 宿主 | 位置 |
|---|---|
| DSH / Codex 类 | `~/.dsh/AGENTS.md`（软链到产物） |
| Claude Code | `~/.claude/CLAUDE.md`（软链到产物） |
| Cursor | 无文件形式全局规则，降级为项目级放置 |

> 若目标文件已存在且不是 Fasti 创建的软链，`install-host` 会**拒绝覆盖**（保护你的手写内容），需手动合并。

## 设计要点

**唯一真相是事件日志。** 数据目录里只有一个权威文件：

```
~/.fasti/
├── events.jsonl          ← 唯一真相：追加型事件日志，只增不改
├── profile/              ← 派生：当前画像 + 历史时间线（可重建）
├── dist/                 ← 派生：宿主产物（可重建）
├── state/                ← 派生：产物指纹清单 + 写锁
└── exports/              ← export 的输出
```

Markdown 是**出口**，不是仓库。删掉所有派生文件，`recompute` + `render` 能把它们逐字节还原。

**为什么是事件日志而不是一张当前值表：**

- 历史可追溯：能回答"我以前是什么"
- 演进与纠正可分：这是"个人画像"区别于"个人简介"的核心
- 可审计：每次修改都留下时间与来源
- 可迁移：一个 `events.jsonl` 就是全部记忆

**确定性重算。** 画像不落地为真相，每次都由事件现算。同一批事件算多少次，结果都逐字节相同。

## 项目结构

```
workspace/
├── fasti/core/           # 核心层（UI 无关）
│   ├── api.py            #   薄门面：唯一对外接口
│   ├── services/         #   实现：facts / categories / views / lifecycle / verify
│   ├── store.py          #   事件日志存储
│   ├── fold.py           #   事件折叠
│   └── render.py         #   确定性渲染
├── fasti/adapters/       # 界面层（可替换）
│   ├── cli.py            #   命令行
│   └── web.py            #   本机网页表单
└── tests/                # 68 个测试
```

**分层约束**：核心层不得 import `argparse` / `http.server` / `sys.argv`，不得 `print`。界面层可替换——加一个新界面不需要改核心。
