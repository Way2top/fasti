# Fasti 使用与验证手册

> 面向：你（唯一使用者）
> 目的：**不是**测功能（那是 QA 的活），而是用 4 周回答一个问题——**有了它，Agent 真的变好了吗？**

---

## 零、开始前：还差 3 步

1. Developer 完成 UUIDv7 改造（进行中）
2. QA 复验通过
3. **你重建数据目录**（约 2 分钟，见附录 A）

做完这三步，才进入下面的日常。

---

## 一、每天要做的（2–5 分钟）——**全程在网页里，不用碰终端**

### 1.1 打开界面（一次性设置）

桌面上已经放好一个启动器：**`Fasti网页.command`**

- **双击它** → 会弹出一个终端窗口（别关），浏览器自动打开网页
- 用完关掉那个终端窗口，服务就停了

> 每次打开都要双击一次。这是本地网页的正常形态——它只在你看的时候运行。

### 1.2 每天的三类动作（都在网页表单里）

| 你今天遇到的情况 | 在网页上怎么做 |
|---|---|
| **有新信息**（开始学 Rust） | 「新增事实」→ 选类别（当前状态）→ 填内容 → 填「从何时起为真」→ 保存 |
| **情况变了**（Python 换 C++） | 「变更」→ 选那条事实 → 变更类型选 **演进** → 填新内容 + 新的生效时间 → 提交 |
| **记错了** | 「变更」→ 选那条事实 → 变更类型选 **纠正** → 填正确内容 → 提交 |
| **让 Agent 看到最新** | 点「渲染宿主产物」 |

> **三类动作的关键区别**：
> - **演进** = 真的变了（旧值保留为历史）
> - **纠正** = 当初写错了（区间不变，只改内容）
> - 新增 = 一个全新的信息点

### 1.3 其他按钮

| 按钮 | 干什么 |
|---|---|
| 刷新 | 重新读取当前数据 |
| 查询（时点） | 查「2026 年 6 月的我是什么样」 |
| 新增类别 | 加自定义类别（如「家庭情况」） |
| 重算画像 | 从事实重新生成画像 |
| 渲染宿主产物 | **改完一定要点这个**，否则 Agent 看不到 |

### 1.4 每天记一个数字（重要）

在下面「验证日志」表里填一行。**只填 3 个数**：

- 今天维护花了几分钟
- 今天开了几次新会话
- 其中几次你需要主动介绍自己

**这是 4 周后唯一能下结论的证据。** 不记就等于白做。

## 二、每周要做的（5 分钟）

### 2.1 三个检查

```bash
fasti profile show      # 画像现在准吗？有没有过时或错误的信息
fasti profile history   # 历史有没有乱七八糟的记录
fasti verify            # 数据完整性自检（应该 7/7 PASS）
```

### 2.2 更新一次周汇总

在验证日志里填本周那一行。

## 三、第 4 周末：出结论

对照基线（交付前记录）：

| 指标 | 基线 | 目标 | 实际 |
|---|---|---|---|
| 10 次新会话中需要自我介绍的次数 | **8 次** | ≤ 2 次 | ? |
| 日均维护时长 | 无 | ≤ 30 分钟 | ? |
| 中间有没有断更（连续几天不录） | — | 0 天 | ? |

然后试着回答：

> **「Agent 变好了吗？」** —— 必须能说出 **≥3 个具体例子**。
> 说"感觉好一点"不算结论。

如果结论是"没变好"，也要能定位到原因（是画像不准？还是画像里的东西 Agent 根本用不上？）。

## 附录 A：UUIDv7 改造后重建数据

**背景**：v1 → v2 是格式断代，不向后兼容。旧数据会被拒绝，需要重建（现有 2 条测试数据）。

旧数据已备份在 `~/fasti-backup-v1/`。

```bash
# 1. 挪走旧数据（不删，留着对比）
mv ~/.fasti ~/.fasti.v1-bak

# 2. 重建
cd <你的项目目录>/workspace
python3 run.py init
python3 run.py fact add --category tech --content "主力语言：Python" --valid-from 2025-01
python3 run.py fact add --category projects --content "当前项目：Fasti 个人记忆系统" --valid-from 2026-11
python3 run.py render

# 3. 验证
python3 run.py verify --deep
```

**软链会自动恢复**：`~/.dsh/AGENTS.md` 指向 `~/.fasti/dist/AGENTS.md`，路径没变，重建后立即生效，**不需要重新 install-host**。

**验证生效**：开一个新 DSH 会话，问「我的主力语言是什么」。

## 附录 B：终端命令速查（备用，日常用不到）

| 目的 | 命令 |
|---|---|
| 看当前画像 | `fasti profile show` |

| 渲染到宿主 | `fasti render` |
| 数据自检 | `fasti verify` / `fasti verify --deep` |
| 导出备份 | `fasti export --out ~/Desktop/备份` |
| 网页表单 | `fasti web` |
| 看接入状态 | `fasti status` |
